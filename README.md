## 🧠 What is Aletheia?

Aletheia Finance is a **non-custodial AI trading platform** built on the [0G Network](https://0g.ai). It solves the fundamental problem of AI finance: *how do you trust that an AI made the decision, and it wasn't tampered with?*

Every trade Aletheia executes carries a **Proof-of-Inference (PoI)** — a cryptographic signature generated by the 0G Serving network inside a Trusted Execution Environment (TEE). The on-chain `AletheiaVault` smart contract **refuses to execute any trade that lacks a valid PoI**, making the AI's decisions trustless and verifiable by anyone.

> *"Not your keys, not your coins — we applied the same principle to AI decisions."*

### The Verifiable Trade Loop

```
User clicks "Simulate" on a strategy
    ↓
[WatcherService]   Fetches live ETH price from CoinGecko
    ↓
[ServingService]   Sends market context + rulebook hash to 0G Serving node (TEE)
    ↓
[0G Network]       AI executes inference inside TEE, returns decision + PoI signature
    ↓
[VaultService]     Constructs executeTrade() calldata with PoI as payload
    ↓
[AletheiaVault]    Recovers signer from signature → validates against authorizedNodes
    ↓
[On-Chain]         TradeExecuted event emitted on 0G Galileo Testnet ✅
```

## 🚀 Getting Started

### Prerequisites

- [Go 1.21+](https://go.dev/dl/)
- [Node.js 20+](https://nodejs.org/)
- [Git](https://git-scm.com/)

### 1. Clone the Repository

```bash
git clone https://github.com/OdogwuML/aletheia_finance.git
cd aletheia_finance
```

### 2. Configure Environment Variables

```bash
cp .env.example .env
```

Edit `.env` with your values:

```env
# 0G Network
OG_RPC_URL=https://evmrpc-testnet.0g.ai
OG_STORAGE_ENDPOINT=https://indexer-storage-testnet-turbo.0g.ai
AGENT_PRIVATE_KEY=your_private_key_here

# Deployed Vault Contract
VAULT_ADDRESS=0x9b6eF2eb94Fc756D2521DDc42Baeb4Ec3a3454C4

# Supabase
SUPABASE_URL=your_supabase_url
SUPABASE_KEY=your_supabase_anon_key
```

> ⚠️ **Never commit your `.env` file.** It's already in `.gitignore`.

### 3. Start the Backend

```bash
cd backend/cmd/api
go run main.go
```

The API will be available at `http://localhost:8080`. Verify with:
```bash
curl http://localhost:8080/api/v1/health
```

### 4. Start the Frontend

```bash
cd frontend
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to access the app.

## 🔐 Security Model

Aletheia is built on the principle that **neither the developer nor any centralized party can ever move user funds** without a valid AI Proof-of-Inference.

```
┌─────────────────────────────────────────────────────────┐
│  Who can trigger a withdrawal?                          │
│                                                         │
│  ✅ User (self) - always, anytime, full control         │
│  ✅ AletheiaVault - ONLY with valid PoI from 0G Serving │
│                                                         │
│  ❌ Developer            - NO access                    │
│  ❌ Random EOA            - NO access                   │
│  ❌ Unverified AI output  - NO access                   │
└─────────────────────────────────────────────────────────┘
```

The `executeTrade()` function on-chain:
1. Validates the trade hasn't expired
2. Reconstructs the exact message hash from trade parameters
3. Recovers the signer from the PoI signature
4. Checks the signer is in `authorizedNodes` (only set by owner)
5. **If any check fails — reverts. No exceptions.**
